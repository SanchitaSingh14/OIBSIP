# 🎙️ Voice Assistant

A Python-based voice assistant developed as part of the Oasis Infobyte Internship.

The assistant uses speech recognition and text-to-speech technologies to listen to voice commands and respond with useful actions.

## ✨ Features

- 🎤 Voice input using microphone
- 🧠 Speech recognition using SpeechRecognition
- 🔊 Text-to-speech using pyttsx3
- 👋 Responds to "Hello"
- 🕐 Provides the current time
- 📅 Provides the current date
- 🔎 Performs Google searches using voice commands
- ⚠️ Handles speech recognition errors
- 🔁 Continuously listens for commands
- 🚪 Supports exit, quit, and goodbye commands

## 🛠️ Technologies Used

- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- datetime
- webbrowser
